# Marvel 5E — Powersets, catalogue initial v0.1

Installation : décompresser le dossier `marvel5e-powersets-starter` dans le répertoire `Data/modules` de Foundry, puis activer le module dans un monde utilisant dnd5e.

À la première ouverture par un MJ, le module crée **cinq compendiums de monde** (Energy, Mystical, Travel, Physical, Specialization), contenant **45 fiches de référence** des powersets du manuel. Ces compendiums appartiennent au monde, et non au module, et demeurent si le module est désactivé.

**Limite de cette première version :** les fiches recensent les noms des powersets, mais ne contiennent PAS encore tous les spells/powers ni leurs effets jouables. Aucun texte original du manuel n'est reproduit. Pour les mécaniques détaillées, se reporter au manuel.
